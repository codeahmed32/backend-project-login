# AuthShield - Authentication & User Management API

A secure RESTful backend service built with Node.js, Express, and MongoDB. It manages user authentication, password hashing, JWT-based session security, and protected API routes.

## 🚀 Features

* **User Authentication:** Secure Login and Registration endpoints.
* **Password Security:** Password hashing using bcrypt/bcryptjs prior to database persistence.
* **JWT Authorization:** Session management via JSON Web Tokens for protecting private backend routes.
* **Database Integration:** MongoDB with Mongoose ORM for structured user data modeling.
* **CORS & Environment Control:** Middleware integration for cross-origin security and strict environment variable handling.

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB (Mongoose)
* **Security:** JSON Web Tokens (JWT), Bcrypt
* **Deployment:** Railway / Render
